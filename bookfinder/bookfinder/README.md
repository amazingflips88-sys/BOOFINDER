# Private Used-Book Finder — V3

V3 is designed for used-book Amazon sourcing using generic Keepa **USED** market history rather than an assumed FBA price premium.

## V3 additions
- Discovery looks for current Used prices below historical Used value.
- Conservative intrinsic value from the lower band of generic Used price history.
- 365-day Used median for context.
- Recurring seasonal model requiring at least two prior years.
- 90-day sales-rank-drop proxy for demand.
- Mini Keepa-style charts: black Used-price line + green sales-rank line.
- Max-buy calculation and BUY NOW / BUY & HOLD / REVIEW / PASS decisions.
- Direct Amazon and full Keepa links.

## Important
Keepa market prices and rank drops are signals, not guarantees. Verify the exact offer, condition, edition, seller, eligibility and checkout price before purchasing. Amazon fee input remains a placeholder until a fee API/model is integrated.
